# DCIT 26 React Calculator

A simple responsive calculator made with React and Tailwind CSS.

## Requirements
- Node.js installed
- VS Code recommended

## Run locally

Open this folder in VS Code, then open the terminal and run:

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually:

http://localhost:5173

## Build for deployment

```bash
npm run build
```

## Vercel deployment

1. Upload this project to a GitHub repository.
2. Open Vercel and import the GitHub repository.
3. Keep the default Vite settings.
4. Deploy.
5. Copy the public `.vercel.app` URL for submission.

## Features
- Number buttons 0–9
- +, −, ×, ÷
- AC reset
- Backspace
- Decimal input
- Equals calculation
- Divide-by-zero error handling
- Keyboard support
- Responsive Tailwind CSS design
- Instructions / User Guide
